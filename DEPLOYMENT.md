# Deployment Guide\n\n## Hosting ClinicCare on GitHub Pages\n\n### Steps to Deploy:\n\n1. **Push to GitHub**\n   ```bash\n   git add .\n   git commit -m \"Initial commit\"\n   git push origin main\n   ```\n\n2. **Enable GitHub Pages**\n   - Go to Repository Settings\n   - Navigate to \"Pages\" section\n   - Select \"main\" branch as source\n   - Click Save\n\n3. **Access Your Website**\n   - Your site will be available at: `https://Andile03-alt.github.io/clinic-appointment-system`\n\n### Local Development\n\n1. **Clone the Repository**\n   ```bash\n   git clone https://github.com/Andile03-alt/clinic-appointment-system.git\n   cd clinic-appointment-system\n   ```\n\n2. **Run Locally**\n   - Simply open `index.html` in your web browser\n   - Or use a local server: `python -m http.server 8000`\n   - Visit: `http://localhost:8000`\n\n## Features Implemented\n\n✅ **Patient Portal**\n- Book appointments\n- View personal medical records\n- Manage patient profile\n- View available doctors\n\n✅ **Staff Dashboard**\n- View daily schedule\n- Manage pending consultations\n- Update patient records\n- Complete appointments\n\n✅ **Admin Panel**\n- View system statistics\n- Manage staff members\n- Configure clinic settings\n- Monitor activity logs\n\n✅ **Analytics Dashboard**\n- Appointment status charts\n- Patient demographics\n- Appointment trends\n- Staff workload metrics\n\n✅ **Interactive Features**\n- Bilingual support (English & SiSwati)\n- Dark/Light theme toggle\n- Responsive design (mobile, tablet, desktop)\n- Real-time data management\n- LocalStorage for data persistence\n\n## Technologies Used\n\n- HTML5\n- CSS3\n- JavaScript (Vanilla)\n- Chart.js (Analytics)\n- LocalStorage API\n\n## Browser Support\n\n- Chrome/Chromium (Latest)\n- Firefox (Latest)\n- Safari (Latest)\n- Edge (Latest)\n- Mobile browsers\n\n## Customization\n\n### Change Clinic Details\nEdit `clinicSettings` in `js/staff.js`:\n```javascript\nlet clinicSettings = {\n    name: 'Your Clinic Name',\n    phone: '+268 XXXX XXXX',\n    hours: '8:00 AM - 5:00 PM',\n    address: 'Your Address'\n};\n```\n\n### Add More Users\nEdit sample data in:\n- `js/patients.js` - Add patients\n- `js/staff.js` - Add staff members\n- `js/appointments.js` - Add appointments\n\n## Troubleshooting\n\n**Charts not displaying?**\n- Ensure Chart.js CDN link is working\n- Check browser console for errors\n\n**Dark theme not working?**\n- Clear browser cache\n- Check localStorage in browser DevTools\n\n**Forms not submitting?**\n- Verify all required fields are filled\n- Check browser console for validation errors\n\n## Future Enhancements\n\n- Backend integration (Node.js/Express)\n- Database (MongoDB/PostgreSQL)\n- User authentication\n- Email/SMS notifications\n- Payment integration\n- Appointment reminders\n- Medical history export (PDF)\n- Advanced search and filtering\n\n## Support\n\nFor issues or questions, please open an issue on GitHub:\nhttps://github.com/Andile03-alt/clinic-appointment-system/issues\n\n## License\n\nMIT License -
